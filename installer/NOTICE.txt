局域网设备加速（旁路由模式）0.5.14（个人免费 / 非商业用途）

项目主页：https://github.com/IMYC001/LAN-side-router-for-windows
支持简体中文 / English，可在设置中切换并保存。
新增关于页面；每台设备自动显示为独立加速卡片，可分别启停和选择节点。

本安装包包含软件、桌面运行环境、独立节点核心和 Windows Packet Filter 原厂完整驱动安装包。
安装到当前 Windows 账户；驱动安装后可被整台电脑上的软件共用。

检测到原有 Npcap 或 Windows Packet Filter 时直接复用，不升级或替换它们。
缺少驱动时，在你确认后请求管理员权限安装 Windows Packet Filter。
安装和卸载驱动可能短暂断网，也可能需要重启；开始前请保存其他工作。
不会修改 Windows 默认网关、DNS、路由、防火墙或 Clash 设置。

卸载前必须停止加速、退出软件，并将设备的 IP 和 DNS 恢复到原来的设置。
卸载会删除当前账户的订阅、备份、会话记录和临时配置；这些数据不能恢复。
原有共享驱动不会被删除。本软件新装的驱动，卸载时会询问是否一并删除；
如果其他软件已开始共用该驱动，请选择保留。
若驱动被其他程序升级、文件被占用或需要重启，卸载会停止并说明原因，
请解决后重试。不会强制终止转发进程或强制删除在用驱动。
Windows 自己维护的事件日志、安装缓存、预读取记录等不属于本软件可安全擦除的内容。

Windows Packet Filter 原厂许可随本包提供，仅按其免费及非营利条款打包。
商业分发前需取得厂商授权。

此前的转发速度问题已在 0.5.5 修复，并由用户实测确认。
实际速度仍取决于电脑、局域网、驱动和所选节点。
公网 ICMP 不支持。只有软件显示的虚拟默认网关回应 ping；
不影响已有 TCP/UDP 游戏转发，也不将 ping 伪造成节点延迟。
