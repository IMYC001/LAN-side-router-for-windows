# PS5 Windows 旁路加速：0.2 开发历史

> Public archive: local network/device identifiers below are illustrative replacements. Historical sections describe their original development stage.

Windows 同局域网游戏网关，版本 `0.2.4-duplex-diagnostics`。

已实现手动网关、目标识别、TCP/UDP/DNS 转发和限时测试。首次 PS5 连接成功、NAT 类型 3；源端口复用修正版实机复测中，用户报告 **NAT 类型 2**。游戏、语音、延迟和长时间稳定性尚未验收。启动应用只读取网络状态；只有用户确认后启动的管理员辅助进程才会打开真实网卡。

用户随后报告转发测速明显低于未加速时。0.2.2 将网卡接收改为即时交付和事件通知，配置 4 MiB 接收缓冲，新增实时 Mbps 与捕获缓冲丢包计数。0.2.3 将物理网卡出站帧改为 Npcap Windows 批量发送队列，减少逐帧进入驱动的调用次数。用户复测仍低于 10 Mbps，并报告流量间歇增长。

0.2.4 为接收和发送分别打开 Npcap 句柄，避免同步发送占用接收锁、延迟 TCP ACK。移除接收与批量入队时的逐包磁盘心跳检查；独立监视器每 50 ms 检查停止与心跳，每批真正发送前仍检查磁盘停止状态，保留 180 秒期限和 8 秒心跳失效保护。每 500 ms 在会话目录记录 `performance.jsonl`，包含速率、TCP 重传/超时、队列、代理 TCP 读取量及驱动发送耗时，不含数据包载荷或订阅信息。实际 PS5 速度尚待复测，不能仅凭代码或离线速率认定慢速原因已解决。

## 运行

打开 `dist/Accelerator/Accelerator.exe`。目录包含 Windows x64 自包含运行时，不需要另装 .NET。

- “主机加速”：生成 IPv4、子网掩码、默认网关和 DNS 预览。暂勿提前填写 PS5；先完成目标只读观察，再另行确认限时实机测试。
- 测试期间显示实时上传/下载 Mbps、累计流量和捕获缓冲丢包。Mbps 是兆比特每秒，8 Mbps 约为 1 MB/s；捕获丢包仅统计本次接收缓冲丢弃，不代表整条网络无丢包。
- “设备与网络”：读取物理网卡和系统已有邻居表，不主动扫描。
- “代理入口”：填写现有 Clash 的回环 SOCKS5 / Mixed 端口；TCP/UDP 检查发送少量 TLS 与 DNS 请求。“检查 UDP 映射”通过现有代理发送四次 STUN 请求，不接管 PS5。
- “订阅”：读取 HTTPS Clash YAML 或本地 YAML，显示节点统计。原始内容与地址不保存；不运行配置、不执行脚本、不拉取 provider。
- “接管计划”：重新读取网络状态，检查指定设备、网关、驱动与 IPv6。只预览。
- “离线验证”：在内存中模拟设备与网关，验证 TCP/UDP 往返，不访问公网或物理网卡。

当前 PS5 转发复用现有 Clash 入口，受其规则和节点选择影响。订阅解析不代表已启用独立订阅出口。

## 手动网关测试

1. 确认物理网卡及 PS5 原 IP/MAC。“检查主机连接”通过 Windows ARP 查询原 IP，核对返回 MAC；会发送少量 ARP 请求，不转发 PS5 流量。查询失败不能单独证明 PS5 离线，成功也不代表 WLAN 发送能力通过。检查前保持 PS5 原网络设置。
2. 检查 PS5 IPv6。仅有 `fe80::` 地址不能证明没有其他 IPv6 地址；界面允许明确接受仅 IPv4 的限时测试，并保留 IPv6 绕行未验证的提示。
3. 首次网卡发送和 PS5 手动设置需要明确授权。接受限时测试、确认恢复方式后，才启动最多 180 秒的网关；填写前记录 PS5 原设置。
4. 只有界面显示网关等待状态后，才在 PS5 填写四项参数。软件按目标 MAC/IP 识别；只有收到真实代理返回数据才显示连接状态，不能据此宣称游戏/NAT 已通过。
5. **停止、超时、失败或电脑断电后，把 PS5 的 IP 与 DNS 恢复自动获取；若原来是自定义配置，则恢复原值。软件不能远程改回 PS5 设置。**

候选预览为 `10.254.83.2` / `255.255.255.252` / `10.254.83.1` / `10.254.83.1`，按现有网卡前缀检查重叠后选择。必须以新预览为准，暂勿提前填写。

网关只回应确认主机对自建 /30 地址的 ARP，不冒用真实路由、不提供 DHCP。DNS 53 端口经 SOCKS5 映射到 `1.1.1.1:53`，返回时保留虚拟网关源地址。其他私网、回环、链路本地、CGNAT、fake-IP 目的地址不转发。只回应自身网关的 ICMP，不伪造公网 ping。

辅助进程有独立期限、8 秒界面心跳和停止文件，发送前检查停止状态；每 5 秒检查物理网卡变化。捕获、注入及已记录的代理会话建立/上传失败会停止。UDP 静默丢包或普通空闲超时并不都计为失败，不能替代游戏连通性测试。退出关闭捕获和代理会话，但 PS5 手动配置需要用户恢复。

2026-10-13 已完成目标捕获和用户手动网关实测。首次用户反馈 NAT 类型 3；0.2.1 于 20:18–20:21 限时复测，用户报告 NAT 类型 2。该轮 TCP 121、UDP 112 流，共创建 108 个 UDP 代理会话，上传约 29.2 MB、下载约 76.7 MB，未记录转发失败。辅助程序已停止，随后检查物理网卡配置和原有 Meta TUN 状态未变。此结果不证明游戏延迟、语音、长时间稳定性或所有节点下的 NAT 2。

`0.1.1` 修复部分订阅服务返回 403 的问题：下载请求支持 gzip、deflate 和 Brotli 压缩，自动发送 `Accept-Encoding`；解压后的内容仍限制在 8 MiB 内。已用用户提供的订阅验证读取和解析，没有保存地址或节点凭据。

## 实际架构

```text
PS5 手动 IPv4 / 自建网关 ARP
  -> 选定 IP/MAC 二层过滤
  -> gVisor / tun2socks 独立 TCP/UDP 协议栈
  -> 127.0.0.1 上的 SOCKS5 CONNECT / UDP ASSOCIATE
  -> 现有 Clash
  -> 游戏节点
  -> Npcap 以太网回包给 PS5
```

独立协议栈处理 TCP 序列、重传与 IPv4 UDP 分片。应用不建立第二个 TUN，不修改电脑默认网关，不启用 Windows IP 转发。

Npcap 桥接、目标 WLAN 收发和限时辅助程序已完成首次实测。旧 ARP 接管/还原构造器仍只用于离线测试，当前手动网关不使用它。用户提供的 UU 研究作为流程和架构参考，不将静态推断当成实机证据；不调用 UU 专有组件。

首次实测使用按目标创建 UDP 代理会话的版本。随后通过现有 Clash 的只读 STUN 检查，观察到同一代理会话访问两个不同服务时公网映射一致，另开会话则不同。当前修正版改为按主机 IP/源端口复用 UDP 代理会话，已通过离线并发、回包来源、不同源端口隔离与关闭测试；实机复测中用户报告 NAT 类型 2。前后结果不单独证明唯一原因。网关 DNS 重写使用独立映射，防止与直连 DNS 的返回来源混淆。

## 已验证

- 模拟 PS5 与网关在两个内存协议栈中完成 TCP 26,000 字节往返。
- UDP 1、64、1,200、4,096 字节往返，包含超过 1,500 MTU 的 IPv4 分片/重组。
- 非目标 MAC/IP、IPv6、非回环代理入口和异常 SOCKS5 数据报被拒绝。
- 自身、网关、跨子网、广播/网络地址以及虚拟网卡不通过计划检查。
- 订阅解析错误不会输出节点密码。
- 普通 JSON `start` / `arp` / `capture` / `install-driver` 命令明确拒绝；真实收发只能由单独确认的限时 worker 启动。
- DNS TCP/UDP 在内存协议栈往返，返回源为虚拟网关，载荷一致。
- 非目标观察拒绝、只读观察无发送、网段冲突和预览参数变化拒绝、捕获失败与到期清理。
- 六个页面在 1180×850、960×700 窗口下生成截图。
- 程序关闭清理协议栈和代理会话。

这些是软件/模拟验证，**不是 PS5 实机、游戏延迟、NAT 类型或 Clash TUN 共存验收**。

2. 已知 PS5 原 IPv4 为 `192.168.50.20`、MAC 为 `02-00-00-00-00-20`。确认仍在同一局域网；实际手动测试会使用新分配网段，不要求与电脑同一 IPv4 子网。
3. 确认 PS5 是否有公网 IPv6。当前手动网关不覆盖 IPv6；不能靠关闭电脑 IPv6 解决 PS5 绕行。
4. 目标只读观察已通过。用户已持续授权不会导致断网的操作，并接受首次最长 3 分钟实机测试；公网 IPv6 未证实，按仅 IPv4 测试处理，填写前仍需记录 PS5 原设置。

本次已授权测试可通过显式启动参数 `--authorized-gateway-test "<只读检查目录>"` 沿用近期检查记录。普通启动不会沿用或自动启用测试。记录必须在 10 分钟内、辅助程序成功退出、收到确认目标数据且发送/转发为零，目标 IP/MAC 和当前物理网卡 GUID/IP/MAC/前缀/网关必须匹配；不满足则停止准备。

启动不会自动执行驱动安装或真实收发。限时测试会发目标 ARP 应答与返回帧；不修改 Windows 路由、地址、转发或防火墙。


## 下一轮测试停止条件

仅当用户授权后讨论并执行。首次现场测试需预先保存 PS5 原设置，最长 180 秒。出现 PC 断网、PS5 断网、网卡状态变化、转发失败或 WLAN 不支持发送，立刻停止，不继续扩大测试范围。软件停止或电脑断电不自动改回 PS5 手动网关，需恢复自动获取 IP/DNS 或原自定义设置，不能宣称完全无中断。
