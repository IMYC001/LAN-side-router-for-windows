# 局域网设备加速器 / LAN Device Accelerator 0.5.14

**简体中文** · [English](#english)

这是本项目的首个完整开源发布：让 Windows 电脑在同一局域网中作为设备代理网关，使用已有 Clash 订阅转发 IPv4 TCP/UDP。设备填写软件生成的四项网络参数即可接入，无需安装客户端或预填 IP/MAC。

![设备加速卡片](https://raw.githubusercontent.com/IMYC001/LAN-side-router-for-windows/v0.5.14/docs/images/device-card-zh.png)

*截图为离线演示数据，不代表带宽或延迟承诺。*

## 本版内容

- 包含 0.5.13 全部功能，并修复云端冷构建验证发现的订阅超时/取消边界误报成功问题。
- 独立设备卡片：分别开始/停止、命名、选择节点、查看流量与网络参数。
- 多订阅信息卡片、服务商额度、节点延迟测试、账户加密保存。
- 默认独立 Mihomo 节点；可选现有 Clash 入口，与电脑 Clash TUN 共存的配置入口保留。
- 深浅主题及五种主题色；设置中即时切换简体中文 / English，关于页包含项目与联系信息。
- Windows 安装程序，附第三方许可与固定 Mihomo 版本对应源码。
- 完整 WPF / Go / 安装器 / 构建脚本 / 测试源码公开。

此前转发速度问题已在 0.5.5 修复并由原用户实测确认；每个网络、节点和设备的表现仍需实际验证。

## 使用须知

1. Windows 10 2004+ / Windows 11 x64，电脑和设备同局域网，设备允许手动 IPv4 设置。
2. 导入自己的订阅并选节点；点击开始，等网关就绪后填写对应卡片的 IP、掩码、网关和 DNS。
3. Clash 共存出口需将 Clash 设为全局；独立订阅是默认出口。
4. 停止或电脑退出后必须恢复设备原 IP/DNS。仅支持 IPv4，公网 ICMP 不转发；不保证 NAT 2 或所有游戏兼容。
5. 驱动安装/卸载可能短暂断网或要求重启，必须明确同意；已有驱动优先复用。应用/安装器未代码签名，原厂驱动 MSI 的签名已验证。

## English

The first complete open-source release. Use a Windows PC as a same-LAN proxy gateway and forward a device's IPv4 TCP/UDP traffic through your existing Clash nodes. Enter the generated network settings on the device; no target-side client or pre-entered IP/MAC is needed.

![English interface](https://raw.githubusercontent.com/IMYC001/LAN-side-router-for-windows/v0.5.14/docs/images/acceleration-en.png)

*Screenshots use offline demonstration data, not a throughput or latency guarantee.*

### Highlights

- All 0.5.13 features, plus a subscription cancellation/deadline fix found during clean Windows validation.
- Independent device cards, start/stop controls, names, node selection, counters and network parameters.
- Multiple subscription cards, provider quota, direct node latency and DPAPI-encrypted persistence.
- Default standalone Mihomo exit, plus an optional existing Clash endpoint.
- Light/dark themes, five accents, live Chinese/English switching and an About page.
- Windows setup package with third-party notices and pinned Mihomo corresponding source.
- Complete WPF, Go, installer, build-script and test source.

The earlier throughput issue was fixed in 0.5.5 and confirmed by the original user. Results still depend on hardware, network and node.

### Files and Usage

- **Setup EXE**: recommended; includes runtime, core and complete vendor Windows Packet Filter driver installer.
- **SHA256SUMS.txt**: release checksums. GitHub's Source code archives contain buildable project source.

Requires x64 Windows 10 2004+ or Windows 11, a shared LAN, and a device with manual IPv4 settings. Import a subscription, select a node, start a card and wait for gateway-ready status before entering its four parameters. Existing Clash mode requires Global mode.

Restore the device's original IP/DNS after stopping. IPv6 and public ICMP are not forwarded; NAT Type 2 and game compatibility are not guaranteed. Driver changes require consent and may disconnect or restart the PC. App/setup binaries are unsigned; the vendor MSI signature was verified.

Go tests, static checks, publishing and offline desktop checks passed, including device isolation, profile restarts, localization and theme/layout checks. No physical gateway or driver change was performed during release preparation. Installation/removal, additional PCs and long-running game sessions were not retested.

The installer is built on a GitHub Windows runner from the `v0.5.14` application source tag, with bundled illustrated guides taken from the workflow commit. Only the installer and checksum file are distributed; there is no folder package. Verify downloads against this release's `SHA256SUMS.txt`. Version 0.5.13 remains a source preparation record without a published binary release.

Original source: **GPL-3.0-only**. The optional Windows Packet Filter vendor driver retains its separate EULA and redistribution restrictions. Npcap is not bundled.
