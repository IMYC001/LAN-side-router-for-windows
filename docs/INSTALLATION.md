# 安装版与卸载

版本 0.5.13，2026-10-16。面向 Windows 10 2004 及以上、Windows 11 x64。
软件名称：局域网设备加速（旁路由模式）。
安装程序：`Accelerator-0.5.13-Setup-win-x64.exe`。软件本体未签名；
Windows 可能提示未知发布者。打包的原厂驱动 MSI 签名已验证有效。
**本轮仅构建及离线验证，没有运行实际安装/卸载，也没有更换当前驱动。**

## 安装

- 软件安装到当前账户的 `%LocalAppData%\Programs\LANDeviceAccelerator`，
  无需另装 .NET、Mihomo 或开发工具。开始菜单快捷方式和系统卸载入口同时创建。
- 检测到现有 Npcap 或 Windows Packet Filter 就复用，不升级、不替换。
- 缺少驱动时显示明确的断网/重启提示；勾选同意后才提升权限，
  使用包内完整原厂 Windows Packet Filter 3.6.2.1 x64 MSI 安装。
- 驱动 MSI 和安装维护程序按固定 SHA256 校验包；构建时还核对 Authenticode。
  安装使用 `/norestart`，不会主动重启。返回 3010 时提示需重启。
- 软件或 `accelerator-engine` 仍运行时拒绝安装或卸载。不会强行终止工作中的网关；
  先停止加速、退出托盘，再继续。0.5.2 正常启动也会避让安装维护锁。
- 软件不设置开机启动、计划任务或应用服务，不修改主机路由、DNS、防火墙或 Clash。
  驱动本身由 Windows 注册为系统驱动。
- 当前账户的旧订阅继续保留。换电脑后 DPAPI 数据不可直接解密，需首次导入订阅。

## 卸载

从 Windows“已安装的应用”卸载“局域网设备加速（旁路由模式）”。

1. 先停止加速、退出软件，并将设备 IP/DNS 恢复原值。手动设备配置无法由卸载器远程恢复。
2. 确认删除当前账户的订阅、加密备份、临时明文配置、会话和性能记录。
3. 原有驱动直接保留。本软件安装的驱动会询问是否一并移除；
   若其他软件或其他账户已共用它，选择保留。保留属于明确选择的共享依赖，
   会清掉本软件的所有权记录，不声称驱动也已删除。
4. 选择移除时请求管理员权限，核对机器端所有权、版本及文件校验。
   先执行官方 MSI 卸载，再通过 `pnputil /delete-driver` 清理本次添加的 INF 包；
   不使用强制移除参数。只清理本次新增且内容仍匹配的系统驱动文件，
   以及安装前不存在的指定发布者证书，保留安装前已有内容。
5. 清理 `%LocalAppData%\PS5Accelerator`。只接受当前账户的固定目录，
   删除前扫描全树，遇到符号链接/重解析点拒绝清理，避免影响目录外文件。
6. 删除安装器登记的程序文件、快捷方式和本软件注册表/卸载条目。

驱动被其他程序升级或替换、文件占用、移除等待重启时，会报错并停止卸载，
保留软件和卸载入口，便于重启或解决占用后重试。不会忽略错误宣称完成。
卸载不能做成任意环境下“绝对无残留”的保证：Windows 安装缓存、
事件日志、Prefetch、更新/安全软件记录由系统管理，不能为了清理软件随意擦除。
安装目录中的用户自行添加文件也不会被通配删除。

当前是单账户安装。若同电脑多个账户安装了软件，各自使用系统卸载入口
清理自己的加密设置；驱动是整机共享依赖，不随意删除其他账户的数据。

## 许可与构建

原厂 MSI EULA 明确允许完整软件随免费/非营利产品分发，须保留完整副本及许可。
禁止未经作者书面同意的盈利分发、商业实体向客户分发。此包按个人免费、
非商业用途提供；商业化前须取得厂商许可。

构建：先运行 `scripts/Get-InstallerTools.ps1`，再运行
`scripts/Build-Installer.ps1`。工具下载固定版本，核对 GitHub 官方 SHA256
及发布者签名。MSI 中的许可和 cabinet 通过数据库只读提取，
不执行管理安装或驱动安装动作。Inno Setup 6.7.3 生成可执行安装包。

## 待验收

- 新电脑上驱动安装、重启后首次识别、真实 Ethernet/Wi-Fi 收发；
- 与原有 Npcap/Windows Packet Filter/Clash 共存；
- 新装驱动的完整卸载，包括重启、Driver Store、系统文件和证书前后对比；
- 主动保留共享驱动、驱动被其他程序升级后的拒绝清理及重试；

此前的转发速度问题已在 0.5.5 修复，并由用户实测确认。
该反馈不保证所有电脑、网络、驱动及节点组合均能达到相同速度。

## 界面与语言

设置中的主题色下方可选择简体中文或 English，语言会随当前账户设置加密保存。
切换语言只刷新界面文字，不重启加速会话、不更改设备名、节点名或网络参数。
设置下方的“关于”页提供软件图标、名称、GitHub 项目链接、QQ 和鸣谢。

驱动安装或卸载可能断网；执行这些验收前必须单独确认。
